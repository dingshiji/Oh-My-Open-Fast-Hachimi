# 已验证经验与常见问题

- 主旋律“22秒以后崩坏”常是多声部遮蔽、取到了贝斯/谐波；先试听分离声部，再谈 MIDI 修正。
- MuseScore 的 7 常是七连音；可疑时看原始 MSCZ 时值，导出 MIDI 可能已经损失显示信息。
- 很短的 32 分音符不要靠粗量化吃掉。钢琴试听和歌声试听分别检查。
- 声库的日语鼻音不能被当作完整长音；man/din/don 内的 n 通常 12–45ms 起步。
- “嘴里含水”多来自 VCV 前缀被挤进短音、逐音采样相位不连续；不是混响不足。
- PC-NSF-HiFiGAN 神经声码器改善了连续性，但用户仍觉得偏合成；不要描述为真实人声水平。
- 两个声库各有 B3/G4/C5 录音，约 3519 oto 记录，不能把上下文别名数当独立发音数。
- 经验证的选样阈值：pitch<=62 用 B3，63..71 用 G4，>=72 用 C5；极端音区不保证自然。
- MuseScore Qt 插件错误：启动脚本需清理 QT_/QML 环境并指定自身 platforms；不要破坏全局环境。
- 角色嘴巴上方黑线/悬空：自备原角色时使用贴合曲面和 UV 嘴型；不要把平面嘴巴推离脸部。
- 曼波 max 模型导入曾有 UV/重复面问题；通用测试场景不导入 MAX；自备角色需要另行转换。
- 背景滚动速度不可把 Blender 每秒 UV 位移照抄为 FFmpeg 每帧 scroll；先测一秒位移。新仓库无旧背景。
- 动作节拍按真实 BPM/节拍图走，不能把所有动作片段强行同速循环。二头身动作重定向常有穿地/手臂问题。
- 声库和权重已经放进本地目录不代表 Git 会带走；assets/private、models 必须另行备份/恢复。
- 真实角色视频要自建 assets/private/characters/duo_stage.blend（默认 render_scene.py 只生成球体演示）：对象名/骨骼名/嘴型节点契约见 docs/SCENE_CONTRACT.md；曼波 .max 必须先经 3ds Max 等转成 FBX/GLB。
