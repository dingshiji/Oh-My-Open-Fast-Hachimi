# 可复用制作流程

## 1. 定义任务与时间轴
记录源文件、选段/整首、目标时长、分工、字幕语言、是否保留伴奏、用户已有修改。不要机械地沿用旧歌 BPM、音高或响度。源码下载由用户处理；找到本地文件即可开工。
使用 `scripts/new_project.py` 创建隔离任务；在 STATE.md 写每一步可检查文件。不要覆盖旧任务或用户乐谱。

## 2. 分轨先行
先用 audio.py extract 转 44.1kHz 双声道 WAV；再 separate。输出 vocals/drums/bass/guitar/piano/other，以及 instrumental、melody_instruments、drums_bass。
用户要“原曲去人声伴奏”时使用非 vocals 的总和；要“鼓+贝斯”才使用 drums_bass。不要把这两者混淆。用户给的对白片段也可能自带 BGM；要求不要 BGM 时先分轨。
输出 float WAV 是为了保留头部余量；最终混音统一控制峰值，不能单独把各分轨削平。

## 3. 主旋律与 B 声部
转谱必须从分离声部开始，而非直接对整首混音取最强谱峰。可先使用本地单音 F0；混合伴奏/和弦时需要多音转录再挑选旋律。
优先上传 Muscriptor 前核对该任务音频与具体站点授权，写 consent.json。人声加 `--voice`，器乐不加。服务可能变动，失败时不能谎称完成。提示用户本地识别的效果没有 Muscriptor 好。
长音频拆成 30–60 秒带 1–2 秒上下文的片段，保留每段原始起点，合并时按中心区域取音符避免重复。检测到 MIDI 120 BPM 不代表原曲 120 BPM；秒时间与节拍必须另行对齐。
检查低音、倍频、滑音与装饰音。不要根据“一整节识别失败”自动认定低音是真旋律。弦乐颤动可根据用户意图改为长音。对类似乐句，优先把用户已修订的一段节奏迁移后再核查，避免让用户重复修整首。
B 不应一直同音八分音符，也不应只有简单托底；可用动机、句尾对答、流动旋律或华丽应答。保留节奏正确部分，只改不和谐的音高。对比版放不同谱表/文件并明确标签。

## 4. 乐谱与歌词
双谱表 A=teio，B=manbo。MuseScore 是供用户编辑的中间成果，不要强制所有高音降八度。用户允许的局部高音可以保留。
四分音符承载两个发音：明确拆成两个八分，或在一个音内做两音素；前者会改变节奏。相邻同音且延音线相连，只在第一个音起辅音。三连音/七连音保持真实时值，不凭显示外观擅自改。
score.py extract 利用 MusicXML 秒级映射处理 tempo；检测和弦/重叠即停下提示修谱，不悄悄丢音。
一条 `lyric` 对应一个发音单位，可 `man -> ma+n`。B 常用 man/bo；连续短音可 man bo bo、man man bo bo；六音可 o ma ji ri man bo。A 可 ha chi mi / na me ru do / a shi ga / ha ya ku na ru。用户填写优先。

## 5. 声库合成
这是 Classic 日语 VCV 库（WAV+oto），不是原生中文 AI 声库。使用 PC-NSF-HiFiGAN 对采样频谱与 MIDI F0 连续重建。中文必须近似映射；不能保证标准普通话。
输入秒级 notes.json -> synthesize.py -> 两条干声、phonemes.json、渲染记录。先做 10–30 秒短例。起音前留 0.13 秒，所有混音/字幕/口型同步考虑该偏移。
不要把旧版 B 人声混到新版 B 乐谱。合成后检查两轨等长、非空、有限值、音高/歌词数量；不要以“用了 AI”代替试听。

## 6. 混音与字幕
mix JSON 逐轨配置 trim_start、offset、gain、pan、target_lufs；每个参数都必须有任务依据。常用初始值 A -17/B -21 LUFS；平等轮唱两人均可 -18。这不是固定要求，服从用户音量设置。
字幕用独立 start/end/text，不跟小节硬切；哈基米不能拆成“哈基 / 米南北路”。快速字幕按歌词词组切，避免整段常驻。默认不在字幕前加角色名。
结尾通常 1–2 秒减弱，但不剪掉最后完整字。保留干声、无字幕/字幕源以便修改。

## 7. 平面视频
scripts/render_scene.py 从空场景生成通用双人测试角色、舞台、相机与灯光，无私有模型或场景文件依赖。默认白底，支持任务背景。测试角色不是原版 teio/manbo 外观；原角色需另行取得素材并实现渲染适配。
video.py mouths 把实际合成 phonemes 转为最终时轴；m/b/p 开头短暂闭口，n 收口，元音切换，休止闭嘴。若改成人声素材，需根据其音频/口型重新定位，不能沿用旧谱的时间。
默认 1080p30。脚本逐帧计算身体摆动，不使用低采样帧复用；变速音乐需要把恒定 BPM 改为节拍数组插值。先渲染 3–10 秒看嘴巴贴合、脚落地、字幕及动作，再整片。

## 8. 验收与交付
完整 FFmpeg 解码；ffprobe 时长与音轨；起始/中间/结尾帧；音频峰值；所有字幕不越界；素材和用户乐谱 hash 不变。
记录已测环境和限制；给 MSCZ、混音和视频链接。若没有工具真正听到音频，不说“已听过，完全正确”。
